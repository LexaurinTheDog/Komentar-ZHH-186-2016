# Komentář k zákonu č. 186/2016 Sb., o hazardních hrách

Odborný komentář k **zákonu č. 186/2016 Sb., o hazardních hrách (ZHH)** — reformnímu kodexu hazardu, který nahradil loterní zákon z roku 1990: druhy hazardních her, ochrana hráčů a rejstřík vyloučených osob, dvoustupňové povolování a obecně závazné vyhlášky obcí, internetová hra a blokace nepovolených nabídek, dozor celní správy.

Konsolidované znění: dokument e-Sbírky `SB-2016-00186_2025-10-01`.
